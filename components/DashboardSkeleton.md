# DashboardSkeleton

> **Advanced.** Available for building custom components. Most apps do not need it.


Skeleton for a dashboard page — a grid of card/stat/chart placeholders
(the `dashboard` fallback).



## Installation

```tsx
import { DashboardSkeleton } from 'uxp/components';
```

## Signature

```tsx
const DashboardSkeleton: React.FunctionComponent<{}>
```
