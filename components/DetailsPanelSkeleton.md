# DetailsPanelSkeleton


Skeleton for the master-detail layout — a list column beside an open
details/dashboard panel (the `detailspanel` fallback).



## Installation

```tsx
import { DetailsPanelSkeleton } from 'uxp/components';
```

## Signature

```tsx
const DetailsPanelSkeleton: React.FunctionComponent<{}>
```
