# Label

A simple label. Usually used in conjunction with a FormField




## Installation

```tsx
import { Label } from 'uxp/components';
```

## Signature

```tsx
const Label: React.FunctionComponent<ILabelProps>
```

## Examples

```tsx
<Label>Name</Label>
```
