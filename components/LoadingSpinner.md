# LoadingSpinner

Show a simple loading animation indicator




## Installation

```tsx
import { LoadingSpinner } from 'uxp/components';
```

## Signature

```tsx
const LoadingSpinner: React.FunctionComponent<{
    /**
     * @example "Loading assets"
     */
    message?: string, className?: string, spinnerOnly?: boolean, styles?: CSSProperties
}>
```
