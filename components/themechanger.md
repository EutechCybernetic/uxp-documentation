# ThemeChanger





This component allows us to switch themes in uxp





## Installation



```tsx
import {ThemeChanger} from 'uxp/components';
```

## Examples



```tsx
<ThemeChanger />
```

## Properties

|Name|Type|Description|
|-|-|-|
|rootElementId|string|pass a element id to apply theme changes to that element and children |
