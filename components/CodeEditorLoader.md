# CodeEditorLoader



Code editor loader — editor-shaped skeleton (gutter + pulsing code lines),
shown while the editors chunk and the monaco runtime bundle download.



## Installation

```tsx
import { CodeEditorLoader } from 'uxp/components';
```

## Signature

```tsx
const CodeEditorLoader: React.FunctionComponent<IWidgetPreloaderLoaderProps>
```
