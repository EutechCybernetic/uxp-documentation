# ViewSkeleton


Generic content-area skeleton for a lazy-loaded view. In v5 the default view is a
list, so this doubles as the `list` fallback. It fills the content region only
(the app shell — header + sidebar — is already mounted around it).



## Installation

```tsx
import { ViewSkeleton } from 'uxp/components';
```

## Signature

```tsx
const ViewSkeleton: React.FunctionComponent<{}>
```
