# Component reference

The generated API reference for the `uxp/components` library, built from the source on every docs publish.

- [Components](components.md): every React component, with its props and, where one exists, a live demo.
- [Hooks](hooks.md): the hooks exported by the library.
- [Types](types.md): the TypeScript types used by components and hooks.
- [Functions](functions.md): the utility functions exported by the library.

For how to use these in an app or a bundle, start with [Components and modes](uxp/components-and-modes.md).
