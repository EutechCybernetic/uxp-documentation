# getModuleIdFromScriptPath


Extracts module ID from script path



## Installation

```tsx
import { getModuleIdFromScriptPath } from 'uxp/components';
```

## Signature

```tsx
function getModuleIdFromScriptPath(scriptPath: string): string
```

## Examples

```tsx
const moduleId = getModuleIdFromScriptPath('/api/UXP/module?id=dashboard-module');
```
