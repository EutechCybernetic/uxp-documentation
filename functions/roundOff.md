# roundOff


Rounds a number to specified decimal places



## Installation

```tsx
import { roundOff } from 'uxp/components';
```

## Signature

```tsx
function roundOff(num: number, decimalPlaces?: number): number
```

## Examples

```tsx
const rounded = roundOff(3.14159, 2);
console.log(rounded); // 3.14
```
