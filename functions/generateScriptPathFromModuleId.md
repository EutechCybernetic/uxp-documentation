# generateScriptPathFromModuleId


Generates a script path from module ID



## Installation

```tsx
import { generateScriptPathFromModuleId } from 'uxp/components';
```

## Signature

```tsx
function generateScriptPathFromModuleId(moduleId: string, lucyUrl?: string): string
```

## Examples

```tsx
const path = generateScriptPathFromModuleId('dashboard-module', 'https://app.example.com');
```
