# publishMessage

Publish a message to a channel



## Installation

```tsx
import { publishMessage } from 'uxp/components';
```

## Signature

```tsx
function publishMessage(context: IContextProvider, channel: string, message: string): IPublishMessage
```

## Examples

```tsx
publishMessage(props.uxpContext, "visitor-arrival", JSON.stringify({ visitorId: 123 }));
```
