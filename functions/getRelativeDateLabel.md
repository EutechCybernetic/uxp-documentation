# getRelativeDateLabel


Gets human-readable label for relative date strings



## Installation

```tsx
import { getRelativeDateLabel } from 'uxp/components';
```

## Signature

```tsx
function getRelativeDateLabel(relativeDate: string): string
```

## Examples

```tsx
const label = getRelativeDateLabel('-3d');
console.log(label); // "3 Days Before"
```
