# QA Guide

Testing guidelines for the v5 framework and base applications, written for the QA team to plan end-to-end tests. The guide is grouped by release: test a build against the pages for its release and every release before it.

- [v5.0.0](v5.0.0/README.md): the v5 migration: authentication, navigation, theming, notifications, migrated apps, widgets and dashboards, customization, bulk import, data export and the point configuration tool.
- [v5.0.1](v5.0.1/README.md): patch release bug fixes, plus configuration packages — export and import for themes, branding, the login page, navigation and notification categories.
- [v5.0.2](v5.0.2/README.md): patch release bug fixes, grouped by app — the password email when registering a user, the stale Email error on Edit User, reporting a missing or unusable notification template instead of sending nothing, the Lucy debugger on the MongoDB debug store, connector logs paging, View Logs and Go to connector in the model designer, account date formats in Lucy, connector credentials refreshing, and no OAuth tokens in the engine log.
- [v5.1.0](v5.1.0/README.md): new features: page view analytics, the media library and the widget designer.
