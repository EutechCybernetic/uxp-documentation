# Data Explorer

Explore the data sources available across the platform and the relationships between them.

- **Catalog Designer:** see the data sources available in the Data Explorer, and create or edit relationships between items.
- **IQL Playground:** write and test IQL queries.

- **What to check:**
  - Catalog Designer lists the available data sources.
  - Create, edit and delete a relationship between two items; the change persists.
  - IQL Playground runs a query and shows the results; an invalid query shows a clear error.
