# Digital Twin App

- **Portfolio View:** a new dashboard view with a tree view on the left and a location filter and date-range filter across the top. Use it to configure a tree-navigation-based dashboard.
- **Floor plan overlays:** overlay one layout on top of another.
  - Upload the main layout.
  - Upload a second layout under a different layout type, making its background transparent on upload.
  - On the first layout, click the config button for overlays, select the other layout to overlay, adjust the size and save.
- **Import / Export** of digital twin configuration data.

- **What to check:**
  - Portfolio View: the tree navigates and the location and date-range filters apply to the dashboard.
  - Floor plan overlay: upload two layouts, overlay the second on the first, adjust the size, save, and confirm it shows.
  - Export the digital twin configuration, then import it and confirm the configuration is restored.
