# useIsTouchScreen

True on a touch screen (a finger is the main input), whatever the screen size. The JS twin of
the `on-touch` SCSS mixin: use it when touch needs different markup, not just different styles.



## Installation

```tsx
import { useIsTouchScreen } from 'uxp/components';
```

## Signature

```tsx
function useIsTouchScreen(): boolean
```
