# useHasMobileCloseBar

True while the mobile shell's footer shows a Close bar (an open layer can be closed from it).
Leave out your own close button then: the Close bar and the phone's Back already close it.



## Installation

```tsx
import { useHasMobileCloseBar } from 'uxp/components';
```

## Signature

```tsx
function useHasMobileCloseBar(): boolean
```
