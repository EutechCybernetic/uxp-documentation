# useWidgetCache


Low-level hook for managing widget/UI cache with localStorage persistence
Single source of truth for widget data across the application


## Installation

```tsx
import { useWidgetCache } from 'uxp/components';
```

## Signature

```tsx
function useWidgetCache(options?: UseWidgetCacheOptions): UseWidgetCacheReturn
```
