# useDrawerItems


Widget drawer specific hook for filtering, pagination, and search
Uses useWidgetCache internally for data management


## Installation

```tsx
import { useDrawerItems } from 'uxp/components';
```

## Signature

```tsx
function useDrawerItems(options: UseDrawerItemsOptions): UseDrawerItemsReturn
```
