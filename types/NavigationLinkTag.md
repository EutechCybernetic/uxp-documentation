# NavigationLinkTag

A navigation link tag: the chip's label and its uxp Chip variant (default secondary).


## Definition

```tsx
export interface NavigationLinkTag {
    label: string;
    variant?: 'primary' | 'secondary' | 'danger' | 'warning' | 'info' | 'success';
}
```

## Usage

```tsx
import { NavigationLinkTag } from 'uxp/components';
```
