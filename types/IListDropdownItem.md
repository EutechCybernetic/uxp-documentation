# IListDropdownItem


An item with a second, muted line, e.g. a changed field and its old and new value


## Definition

```tsx
interface IListDropdownItem {
    /** The item's name */
    label: string;
    /** A muted line under the name */
    detail?: string;
}
```

## Usage

```tsx
import { IListDropdownItem } from 'uxp/components';
```
