# undefined


Tab identifiers accepted by MarkdownEditor.

- mode="markdown": 'write' | 'preview' (native). 'editor' and 'markdown'
  map to 'write'.
- mode="rich": 'editor' | 'markdown' (native). 'write' and 'preview' map
  to 'editor' — the rich surface is both the editor and the preview.


## Definition

```tsx
export type MarkdownEditorTab = 'write' | 'preview' | 'editor' | 'markdown';
```

## Usage

```tsx
import { undefined } from 'uxp/components';
```
