# ISpecialDate




Spacial date options




```tsx
interface ISpecialDate {
    /**
     * special date 
     */
    date: string | Date,
    /**
     * Text to show on tootltip 
     */
    label?: string
    /**
     * background color for the date 
     */
    backgroundColor?: string
    /**
     * text color for the date 
     */
    color?: string
}
```

## Usage



```tsx
import {ISpecialDate} from 'uxp/components';
```
