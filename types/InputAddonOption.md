# InputAddonOption


A single option inside an addon dropdown.


## Definition

```tsx
export interface InputAddonOption {
    label: string;
    value: string;
    /**
     * Optional icon — FontAwesome string ("fas flag") or an image URL.
     */
    icon?: string;
}
```

## Usage

```tsx
import { InputAddonOption } from 'uxp/components';
```
