# ContextDatasection


Groups related pill options under a section header


## Definition

```tsx
export interface ContextDatasection {
    /** Section header text */
    label: string;
    /** Available options in this section */
    fields: PillOption[];
}
```

## Usage

```tsx
import { ContextDatasection } from 'uxp/components';
```
