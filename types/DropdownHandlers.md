# DropdownHandlers


Handlers exposed by the Dropdown component for external control.


## Definition

```tsx
export interface DropdownHandlers {
    /**
     * Opens the dropdown.
     */
    open: () => void;

    /**
     * Closes the dropdown.
     */
    close: () => void;
}
```

## Usage

```tsx
import { DropdownHandlers } from 'uxp/components';
```
