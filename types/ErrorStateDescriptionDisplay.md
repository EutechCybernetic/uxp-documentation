# undefined


Where the description goes in `inline` mode.

- `dropdown` (default): opens from the icon on click, the same way `indicator` mode
  reveals its detail, keeping the row to one line.
- `inline`: rendered under the title.
- `hidden`: not rendered at all.


## Definition

```tsx
export type ErrorStateDescriptionDisplay = 'dropdown' | 'inline' | 'hidden';
```

## Usage

```tsx
import { undefined } from 'uxp/components';
```
