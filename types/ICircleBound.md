# ICircleBound


Circle bounds definition


## Definition

```tsx
export interface ICircleBound {
    /**
     * center of the circle
     */
    center: [number, number],
    /**
     * radius of the circle
     */
    radius: number
}
```

## Usage

```tsx
import { ICircleBound } from 'uxp/components';
```

## Examples

```tsx
tsx
{
  center: [1.29, 103.85],
  radius: 2000
}
```
