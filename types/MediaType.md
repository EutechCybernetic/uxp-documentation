# undefined


The kinds of media a picker can deal with. `Icon` is a *picker* type only —
it turns on the font-icon source; uploads are never classified as Icon
(their type always comes from the MIME type).


## Definition

```tsx
export type MediaType = 'Image' | 'Icon' | 'Document' | 'Video' | 'Audio'
```

## Usage

```tsx
import { undefined } from 'uxp/components';
```
