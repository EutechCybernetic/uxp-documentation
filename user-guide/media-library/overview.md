# Your media library

The media library is where the files you upload are kept, so you can find and reuse them later. Whenever a form or setting asks you to choose an image, icon, document, video or audio file, the same picker opens — and everything you have ever uploaded through it is waiting on the first tab.

## What the media library is

Across the platform, any field that takes a file uses one shared picker. Upload a logo on one screen and it is there, ready to pick again, on every other screen that takes an image. You never have to upload the same file twice.

The library is your own. Each user has a separate library, and you only ever see your own uploads. Nobody else sees yours, and you do not see theirs.

## The picker and its sources

When you open a media field, the picker shows the sources you are allowed to choose from. Which ones appear depends on the field — an image field shows the image sources, an icon field shows icons, and so on.

| Source | What it holds |
|---|---|
| My media library | Everything you have uploaded before |
| Image gallery | The platform's stock images |
| Font icons | The built-in icon set |
| Upload | Pick a file from your computer |
| URL | Paste a web address to a file |

Selecting a file:

- In a single-value field, click a file to preview it, then **Select & close** to use it.
- In a field that takes several files, click each file to add it straight away. Your choices appear as a row of cards beneath the field, each with a remove button.

## My Media

To see and manage everything you have uploaded, open **My Media** at `/view/user/my-media`. There is also a link to it at the bottom of the library source in the picker.

My Media lists your files with search and paging, so a long library stays easy to browse.

Deleting a file in My Media removes it from your library only. Anywhere the file was already used — a logo you saved, a document you attached — keeps working, because those places hold the file's own address.

## Saving uploads to your library

New uploads are added to your library automatically. An administrator controls this for the whole account with a switch at **Administration > Account Settings > General > "Save uploads to media library"**.

- The switch is on to start with, so your uploads are saved without you doing anything.
- If an administrator turns it off, new uploads still work — they just are not added to the library. Files already in your library stay there.
